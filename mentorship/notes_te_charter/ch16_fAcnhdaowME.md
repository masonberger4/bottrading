## Summary
Model 6.1: buy-side low-resistance liquidity runs framed on fractal time-frame pairs. Stage TF holds the draw (premium array / buy stops), setup on the next lower TF (market maker sell OR buy model, buy side of the curve), entry pattern "fair value" on the TF below that. Stage-1 reaccumulation appears at 20-30% of the origin-to-terminus range; HTF (4h+) usually gives two buy opportunities, below 4h often one; a rule for when stage 2 will not occur (<= 30 pips left); MM buy model's stage 2 sits opposite the sell-side curve's redistribution (up-close candles).

## Rules
- Time-frame pairing: stage (draw) on weekly -> setup on daily -> entry on 4h; daily draw -> 4h / 60m; 4h -> 60m / 15m; 60m -> 15m and lower ~5:33-6:10, ~23:12-25:50
- "Fair value" entry pattern = an FVG, a liquidity void filled, or a run on sell stops ~6:38-7:09
- If the retracement has an FVG/void, it rebalances there and usually does not run the sell stops (especially after a recent stop run); if there is NO FVG in the consolidation, expect a run of the short-term (15m) low first, then expansion ~7:09-7:58, ~28:40-29:28
- Draw = next high-probability premium array on the HTF (bearish OB, FVG above, old high); whether the HTF move continues later is irrelevant ~8:29-9:29
- Range of opportunity: buy side of the curve, from the discount array to the targeted premium array ~9:29-10:03
- HTF (weekly, daily, 4h) tends to give two buying opportunities before the target; below 4h often just one retracement ~10:40-11:42
- Stage-1 reaccumulation = first buying opportunity after the run starts, at ~20-30% of the anticipated origin-to-terminus range (grade the swing in quadrants 25/50/75/100) ~15:51-17:59
- Stage 2: if the swing falls short and corrects, fib projections (1.27 / 1.68 extensions) of the stage-2 retracement that align with the premium array confirm the long ~17:59-18:58
- If stage 2 is broken and price trades below stage 1, it often runs the sell stops below stage-1 reaccumulation = a third buying opportunity ~18:58-20:02
- When <= 30 pips (10/20/30 sweep grades) remain to terminus after the first leg, there will be no stage 2: do everything on the one entry ~31:38-33:02, ~36:13-36:49
- Last leg (stage 2 -> terminus) is usually the fastest ~32:07
- Use the weekly frame for Mon/Tue/Wed one-shot-one-kill buys between stage points; or swing with partials at the stage high and re-buy (pyramid) on the retracement ~20:32-22:44
- Daily frame: Tue setup -> Wed run -> Thursday reversal profile -> Friday/Monday new buy ~24:27-24:53
- Session use on 4h: start in London, if stage 2 not reached look for NY continuation; leave a piece for terminus ~26:17-26:51
- MM buy model: terminus = run above the original consolidation (+10/20/30 pips); stage-2 reaccumulation = mirror of the sell-side curve's redistribution (its up-close candles) directly across the curve ~35:49-40:43
- Only buy when HTF institutional order flow is bullish (down-close candles supporting, up-close candles broken, new highs held) ~27:45-28:11
- ICT: all his public 2017-18 buys used this model on the 4h, Mon-Wed ~26:51-27:19
